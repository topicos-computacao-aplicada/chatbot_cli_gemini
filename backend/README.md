# Instruções

## Crie suas variáveis de ambiente em um arquivo .env

```bash
DATABASE_URL=sqlite:///./test.db
GEMINI_API_KEY=sua_chave_gemini
GEMINI_MODEL=gemini-2.5-flash
```

## Execução da aplicação

Execute o script da pasta superior

```bash
./start_backend.sh
```

Por padrão a aplicação backend vai rodar na porta 8000.
